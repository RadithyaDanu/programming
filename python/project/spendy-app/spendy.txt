# PROJECT: PROGRAM PENCATAT PENGELUARAN

## TUJUAN PROJECT

Membuat aplikasi sederhana menggunakan Python untuk mencatat dan mengelola pengeluaran.

Project ini dibuat sebagai latihan setelah menyelesaikan materi Python sampai OOP.

Fokus utama project:

* Mengaplikasikan konsep Python yang sudah dipelajari.
* Membiasakan diri membuat program dari nol.
* Melatih problem solving dan struktur program.
* Memahami penggunaan function, list, dictionary, OOP, file handling, dan error handling.
* Mengenal alur sederhana software development.

## SCOPE PROJECT

Aplikasi memiliki fitur utama:

1. Tambah pengeluaran
2. Lihat semua pengeluaran
3. Menghitung total pengeluaran
4. Menghapus pengeluaran
5. Keluar dari aplikasi

Penyimpanan data menggunakan file JSON agar data tidak hilang ketika program ditutup.

## PHASE 2 - DESIGN

Tentukan bagaimana data akan direpresentasikan.

Satu pengeluaran dapat memiliki data:

{
"nama": "Makan siang",
"kategori": "Makanan",
"jumlah": 25000
}

Banyak pengeluaran akan disimpan dalam sebuah list:

pengeluaran = [
{
"nama": "Makan siang",
"kategori": "Makanan",
"jumlah": 25000
},
{
"nama": "Bensin",
"kategori": "Transportasi",
"jumlah": 20000
}
]

Konsep yang digunakan:

LIST
Untuk menyimpan banyak data pengeluaran.

DICTIONARY
Untuk menyimpan informasi dari satu pengeluaran.

====================================

## PHASE 3 - IMPLEMENTASI DASAR

Mulai dengan struktur procedural terlebih dahulu.

Buat beberapa function:

* tambah_pengeluaran()
* lihat_pengeluaran()
* hitung_total()
* hapus_pengeluaran()
* app_menu()

Tujuannya adalah memahami alur program terlebih dahulu.

Jangan langsung menggunakan OOP.

Pastikan versi dasar sudah dapat berjalan sebelum masuk ke tahap berikutnya.

====================================

## PHASE 4 - OOP

Setelah versi dasar selesai, lakukan refactoring menggunakan OOP.

Buat class:

class Pengeluaran

Class ini bertanggung jawab merepresentasikan satu pengeluaran.

Contoh atribut:

* nama
* kategori
* jumlah

Kemudian buat class:

class ExpenseManager

Class ini bertanggung jawab mengelola kumpulan pengeluaran.

Contoh tanggung jawab:

* Menambahkan pengeluaran
* Menampilkan pengeluaran
* Menghitung total
* Menghapus pengeluaran

Tujuan tahap ini bukan sekadar menggunakan class.

Pahami alasan kenapa data dan behavior tertentu dikelompokkan ke dalam sebuah class.

====================================

## PHASE 5 - FILE HANDLING

Tambahkan penyimpanan permanen menggunakan JSON.

Masalah yang ingin diselesaikan:

Jika data hanya disimpan di dalam variable Python, data akan hilang ketika program ditutup.

Solusinya:

Python program
|
v
expenses.json

Ketika program dimulai:

* Baca data dari JSON.
* Masukkan data ke program.

Ketika data berubah:

* Simpan kembali data ke JSON.

Contoh file:

expenses.json

[
{
"nama": "Makan siang",
"kategori": "Makanan",
"jumlah": 25000
}
]

Konsep yang dipelajari:

* Membuka file
* Membaca file
* Menulis file
* JSON
* Serialization / deserialization

====================================

## PHASE 6 - ERROR HANDLING

Tambahkan validasi agar program tidak mudah crash ketika user memberikan input yang salah.

Contoh:

Jumlah: abc

Program tidak boleh langsung crash.

Gunakan:

try:
jumlah = int(input("Jumlah: "))
except ValueError:
print("Jumlah harus berupa angka.")

Tambahkan juga validasi seperti:

* Jumlah harus berupa angka.
* Jumlah harus lebih dari 0.
* Pilihan menu harus tersedia.
* Pengeluaran yang ingin dihapus harus ada.

Gunakan try-except hanya pada bagian yang memang berpotensi menghasilkan error.

Gunakan continue jika input invalid harus mengulang proses.

====================================

## PHASE 7 - TESTING

Setelah program selesai, lakukan pengujian secara manual.

Test case minimum:

1. Tambah satu pengeluaran
   Expected:
   Data berhasil ditambahkan.

2. Tambah beberapa pengeluaran
   Expected:
   Semua data tersimpan.

3. Hitung total
   Expected:
   Total sesuai dengan jumlah seluruh pengeluaran.

4. Input jumlah berupa huruf
   Expected:
   Program menampilkan pesan error dan tidak crash.

5. Input jumlah negatif
   Expected:
   Program menolak input.

6. Hapus pengeluaran
   Expected:
   Data berhasil dihapus.

7. Hapus data yang tidak ada
   Expected:
   Program memberikan pesan yang sesuai.

8. Tutup program lalu jalankan kembali
   Expected:
   Data sebelumnya masih tersedia.

====================================

## PHASE 8 - REFACTORING

* Apakah class memiliki tanggung jawab yang jelas?
* Apakah struktur program mudah dibaca?

Tujuan:

Mengubah kode dari sekadar "bisa jalan" menjadi kode yang lebih rapi dan mudah dipahami.
